## Common problems

**The launcher refuses your Cemu.**
Its message says what is missing: another version of the game, the update or the DLC not installed, a game listed by
Cemu that moved... Fix it in Cemu, start the game once there, and launch again.

**"Close Cemu before preparing a session".**
The launcher starts Cemu itself: close yours first.

**The launcher refuses your seed.**
The seed was generated by another version of BOTW Archipelago, and the launcher names it: play the seed with that
release ([updating](setup_en.md#updating)).

**With mods, the game never finishes loading.**
The game lacks memory. Read what the launcher says about [Extended Memory](mods_en.md#extended-memory), and check that
the same mods load in your own Cemu.

**The game does not react to your controller.**
The profile copied no controller setting from your Cemu. In the game's window, open Cemu's Options > Input settings
and choose your controller for player 1; the profile keeps it.

**The Archipelago logo stays grey.**
The client is not connected to the room. Look at the launcher's window: it says why. The room's address changes when
it restarts on archipelago.gg: take the new one from the room's page.

**The tracker shows something wrong.**
See the [trackers' troubleshooting](poptracker_en.md#troubleshooting).

## Logs

Each session writes its logs to `%LOCALAPPDATA%\BOTW Archipelago\play-seeds\<seed>\sessions\<date>\`: the client's
log, Cemu's log and a summary. Attach that folder when you
[report a problem](https://github.com/EIdras/BOTW-Archipelago/issues).

## Test commands

The client adds a few commands to the launcher's window, for tests and bug reports:

| Command | What it does |
|---|---|
| `/ap-tip <text>` | Show a line in the in-game Archipelago journal |
| `/ap-disconnect [s]` | Simulate a server disconnection for `s` seconds |
| `/ap-evt [n\|reset]` | List the game's last event requests |
| `/ap-deathlink [cause]` | Kill Link as a received DeathLink would (sent to nobody) |
| `/ap-border` | With `region_lock`: Link's position, the nearest closed region and the return to safe ground |
